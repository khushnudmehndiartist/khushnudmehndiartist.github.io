# Khushnud Mehndi Artist 🌿

Premium Mehndi Artist website — showcasing exquisite bridal, Arabic, party, and custom mehndi designs.

![Khushnud Mehndi](assets/images/logo.png)

## ✨ Features

- **Shuffle Hero Carousel** — Slides randomize on every page load with smooth crossfade transitions
- **Gallery with Lightbox** — Click-to-zoom gallery with keyboard navigation (arrows, Esc)
- **Mobile Responsive** — Fully optimized for phones, tablets, and desktops
- **WhatsApp Integration** — Booking form sends pre-formatted message directly to WhatsApp
- **Scroll Animations** — Elements fade-in beautifully as you scroll
- **Touch/Swipe Support** — Swipe gestures for carousels on mobile devices
- **SEO Optimized** — Proper meta tags, semantic HTML, and fast load times

## 🎨 Design

- **Colors**: Deep Burgundy `#800020` + Gold `#D4AF37`
- **Fonts**: Playfair Display (headings) + Lato (body)
- **Style**: Premium, elegant, bridal aesthetic
